# 드래곤 견적 (DRAGON BUILD)

### 🌐 사이트 바로가기 → **https://dragon-build.vercel.app**

예산과 용도만 고르면 PC **꿀조합**(가성비 좋은 부품 조합)을 찾아 주고, 부품별 **최저가~최고가**를 한눈에 보여 주는 사이트입니다.
컴퓨터 부품을 전혀 몰라도 쓸 수 있게 만드는 것이 목표입니다.

| 탭 | 하는 일 |
|---|---|
| **소원 빌기** | 예산(30만~1,000만원)과 용도(게임·편집·AI·사무, 여러 개 선택 가능)를 고르면 드래곤볼 7개가 모이고 신룡이 꿀조합을 꺼내 줍니다. |
| **드래곤 레이더** | CPU·그래픽카드 같은 부품 종류별로 제품을 싼 순서(또는 비싼 순서)로 보여 줍니다. 제품을 누르면 쇼핑몰별 가격이 나옵니다. |
| **캡슐 보관함** | 마음에 든 견적을 저장하고, 두 개를 나란히 비교합니다. |
| **신룡에게 묻기** | "이 조합으로 게임도 돼?" 같은 질문에 AI가 쉬운 말로 답합니다. |

## 바로 실행하기

### 1. 준비물

| 준비물 | 왜 필요한가요? | 확인 방법 |
|---|---|---|
| **Node.js 22 이상** | 사이트 서버를 돌리는 프로그램 | 터미널에 `node -v` |
| **Python 3** + `beautifulsoup4` | 다나와 가격을 읽어 오는 도구(k-skill)가 파이썬으로 되어 있어요 | `python --version`, 설치는 `python -m pip install beautifulsoup4` |
| **API 키 2개** (선택) | AI 상담 기능용. 아래 [외부 도구 설명](#외부-도구는-왜-연결하나요) 참고 | — |

### 2. API 키 넣기

`.env.example` 파일을 복사해서 이름을 `.env`로 바꾸고, `=` 뒤에 키를 붙여 넣습니다.

```
GOOGLE_API_KEY=여기에_구글_AI_Studio_키
FIRECRAWL_API_KEY=여기에_Firecrawl_키
```

> ⚠️ `.env`에는 비밀번호와 같은 키가 들어 있어서 **GitHub에 올라가지 않게** `.gitignore`로 막아 두었습니다. 키를 채팅이나 메신저에 붙여 넣지 마세요.

### 3. 내 컴퓨터에서 켜기

```
npm start
```

브라우저에서 **http://localhost:3000** 을 엽니다.
처음 켜면 다나와 가격을 모으는 데 30초~1분 걸립니다. 그 뒤 6시간 동안은 모아 둔 가격(`data/cache.json`)을 다시 써서 빠릅니다.

### 4. 인터넷에 올리기 (Vercel)

사이트는 [Vercel](https://vercel.com)에 올라가 있습니다. Vercel은 서버를 따로 관리하지 않아도, 요청이 올 때만 코드를 실행해 주는 호스팅 서비스입니다.

```
npx vercel deploy --prod
```

- **API 키:** `.env`가 아니라 Vercel 프로젝트 설정의 **Environment Variables**에 넣어 둡니다(`GOOGLE_API_KEY`, `FIRECRAWL_API_KEY`).
- **서버 위치:** 다나와가 해외 서버를 잘 막아서 함수는 **서울 리전(icn1)**에서 돌게 해 두었습니다(`vercel.json`).
- **가격 저장본:** 그래도 다나와가 클라우드 서버를 막는 때가 있어서, 그럴 땐 내 컴퓨터에서 모아 둔 **가격 저장본**(`lib/snapshot.json`)으로 대신 보여 줍니다. 저장본을 새로 만들려면 아래처럼 한 뒤 다시 배포하세요.

```
npm run snapshot
```

## 외부 도구는 왜 연결하나요?

이 사이트는 혼자서 모든 걸 하지 않고, 잘하는 외부 도구 3개의 힘을 빌립니다.
식당에 비유하면 **사이트는 주방장**이고, 외부 도구는 **재료를 대 주는 거래처**입니다.

| 도구 | 비유 | 담당 기능 | 키 필요? | 없으면? |
|---|---|---|---|---|
| **k-skill 다나와 스킬** | 시장에서 가격표를 받아 오는 심부름꾼 | 모든 부품 가격 | ❌ 필요 없음 | 사이트 핵심 기능이 멈춰요 (필수) |
| **Google Gemini API** | 질문에 답해 주는 상담원 | 신룡에게 묻기 | ✅ `GOOGLE_API_KEY` | 상담 탭만 안 돼요 |
| **Firecrawl API** | 인터넷에서 리뷰를 찾아 주는 조사원 | 상담 답변의 근거 자료 | ✅ `FIRECRAWL_API_KEY` | 상담은 되지만 웹 근거 없이 답해요 |

### 1. k-skill 다나와 스킬 — 부품 가격 담당 (필수)

**무엇인가요?**
[k-skill](https://github.com/NomaDamas/k-skill)은 한국 생활에 필요한 일(기차 조회, 택배 조회, 쇼핑 가격 비교 등)을 AI·프로그램이 대신할 수 있게 만든 오픈소스 도구 모음입니다.
그중 **`danawa-price-search`** 스킬은 가격 비교 사이트 [다나와](https://www.danawa.com)의 공개 검색 결과를 읽어 옵니다.

**왜 연결하나요?**
부품 가격은 매일 바뀝니다. 가격을 직접 적어 두면 금방 틀린 정보가 되기 때문에, 사이트가 열릴 때마다 다나와의 **지금 가격**을 가져와야 합니다.

**연결하면 되는 것**
- 제품 검색: "RTX 5060"을 검색하면 여러 회사 제품과 최저가가 나옵니다.
- 쇼핑몰별 가격: 한 제품을 어느 쇼핑몰에서 얼마에 파는지, **배송비 포함 가격**과 무료배송, 카드 할인, 무이자 할부까지 가져옵니다.
- 결제 조건 구분: "현금 결제 시에만 이 가격" 같은 조건을 알려 줘서 미끼 가격에 속지 않게 합니다.

**예시**
> 소원 빌기에서 "200만원, 영상편집"을 고르면 →
> 사이트가 k-skill로 CPU·메인보드·램·그래픽카드 등 8종의 다나와 가격을 모두 모으고 (이때 드래곤볼이 하나씩 켜져요) →
> 그 가격으로 예산 안에서 가장 알뜰한 조합을 계산합니다.

**알아 둘 점**
- 키가 필요 없고 로그인도 하지 않습니다. **읽기만** 하고, 구매·장바구니·결제는 하지 않습니다.
- 다나와에 부담을 주지 않도록 한 번에 3~4개까지만 조회하고, 결과를 6시간 저장해 둡니다.
- 판매처가 3곳 미만이거나 시세보다 터무니없이 싼 "미끼 가격"은 꿀조합에서 뺍니다.
- k-skill의 다나와 스크립트(v0.10.0, MIT 라이선스)를 `lib/kskill/`에 그대로 넣어 두었습니다. Vercel 서버에서도 따로 설치하지 않고 바로 쓰기 위해서예요.
- 다나와는 예전 검색 화면과 새 검색 화면을 번갈아 보여 줍니다. `lib/danawa_ext.py`가 두 화면을 모두 읽습니다.

### 2. Google Gemini API — 신룡 상담 담당 (선택)

**무엇인가요?**
Google이 만든 AI(제미나이)를 다른 프로그램에서 쓸 수 있게 열어 둔 창구입니다. **API 키**는 그 창구를 쓰기 위한 **출입증**이라고 생각하면 됩니다.

**왜 연결하나요?**
초보자의 질문은 "그래픽카드는 왜 이렇게 비싸?", "게임도 할 건데 괜찮아?"처럼 정해진 버튼으로 답하기 어려운 것이 많습니다. AI를 연결하면 이런 질문에도 대화로 답할 수 있습니다.

**연결하면 되는 것**
- 자유 질문 답변: 전문용어를 쉬운 비유로 풀어서 설명합니다.
- 내 조합 기준 답변: "현재 조합 함께 보내기"를 켜면 지금 만든 견적을 보고 답합니다.
- 바쁠 때 자동 대체: Gemini 서버가 붐비면 다른 Gemini 모델로 자동으로 바꿔서 다시 시도합니다.

**예시**
> 질문: "램 32GB면 충분해?"
> 신룡: "램은 작업 책상의 넓이와 같다. 32GB면 영상 편집을 하면서 브라우저를 여러 개 띄워도 넉넉하니…"

**키 발급 방법**
1. [Google AI Studio](https://aistudio.google.com)에 Google 계정으로 로그인
2. **Get API key → Create API key**
3. 나온 키를 `.env`의 `GOOGLE_API_KEY=` 뒤에 붙여 넣기

> 참고: AI Studio 키(`AQ.`로 시작)는 **Gemini 전용**입니다. YouTube 같은 다른 Google 서비스에는 쓸 수 없어요.

### 3. Firecrawl API — 웹 근거 자료 담당 (선택)

**무엇인가요?**
[Firecrawl](https://firecrawl.dev)은 인터넷을 검색하고 웹페이지 내용을 AI가 읽기 좋은 글로 정리해 주는 서비스입니다.

**왜 연결하나요?**
AI는 학습한 시점 이후의 일을 모르고, 가끔 그럴듯하게 틀린 말을 합니다(이를 "환각"이라고 해요).
"이 그래픽카드 리뷰 어때?"처럼 **최신 평가**가 필요한 질문에서는, 실제 웹 자료를 먼저 찾아 AI에게 건네주면 훨씬 정확해집니다.

**연결하면 되는 것**
- 질문에 "리뷰, 후기, 벤치, 비교, 발열, 소음, 프레임, 호환" 같은 말이 들어가면 자동으로 웹을 검색합니다.
- 찾은 글 3~4개를 근거로 답하고, 답변 아래에 **참고한 웹 자료 링크**를 붙입니다.

**예시**
> 질문: "RTX 5050 리뷰 어때?"
> → Firecrawl이 리뷰 글·영상 4개를 찾아옴
> → 신룡: "세상의 평가는 그리 밝지 못하구나. 1080p 게임에서는 무난하지만…"
> → 답변 아래: ↗ RTX 5050 리뷰 (Reddit), ↗ RTX 5050 Review (YouTube) …

**키 발급 방법**
1. [firecrawl.dev](https://firecrawl.dev)에 가입
2. 대시보드의 **API Keys**에서 키 복사 (`fc-`로 시작)
3. `.env`의 `FIRECRAWL_API_KEY=` 뒤에 붙여 넣기

### YouTube는요? (현재 연결 안 됨)

이 프로젝트에는 **YouTube가 연결되어 있지 않습니다.** 나중에 기능을 늘릴 때 참고하세요.

**연결하면 할 수 있는 것 (아이디어)**
- 부품 이름으로 리뷰 영상 검색: 드래곤 레이더에서 제품을 누르면 관련 리뷰 영상 3개를 함께 보여 주기
- 영상 정보 가져오기: 조회수, 좋아요 수, 업로드 날짜를 보고 최신·인기 리뷰부터 정렬하기

**필요한 것**
- **YouTube Data API v3 키**(`AIza`로 시작): [Google Cloud Console](https://console.cloud.google.com)에서 YouTube Data API v3를 켜고 발급합니다. 위의 Gemini 키로는 안 됩니다.
- 무료로 하루 10,000유닛을 쓸 수 있습니다. 검색 1번에 100유닛, 영상 정보 조회 1번에 1유닛이 듭니다.
- 읽기만 할 거라면 키 하나로 충분합니다. 댓글 달기나 업로드처럼 **내 계정으로 하는 일**에는 로그인 인증(OAuth)이 따로 필요합니다.

> 💡 **MCP란?** AI 도우미(예: Claude)가 외부 서비스를 직접 쓸 수 있게 해 주는 연결 규격입니다. "YouTube MCP"를 설치하면 AI에게 "이 부품 리뷰 영상 찾아줘"라고 말로 시킬 수 있습니다. 이 사이트는 MCP 대신 각 서비스의 API를 서버 코드에서 직접 부르는 방식을 씁니다.

## 폴더 구성

꿀조합 계산은 **방문자의 브라우저**에서 하고, 서버는 **가격 조회**와 **AI 상담** 두 가지만 맡습니다.

| 파일 | 역할 |
|---|---|
| `public/` | 화면 (`index.html`, `style.css`, `app.js`) |
| `public/shared/catalog.js` | 다룰 CPU·그래픽카드 목록과 성능 점수 (**새 모델은 여기에 추가**) |
| `public/shared/parts.js` | 다나와 결과 → 쉬운 이름·스펙·호환성 정보로 정리 |
| `public/shared/engine.js` | 꿀조합 계산, 부품 업/다운, 호환성 체크, 성능 별점 |
| `api/danawa.py` | (Vercel) 다나와 가격 조회 함수. 막히면 가격 저장본으로 대신 응답 |
| `api/ask.js` | (Vercel) 신룡 상담 함수 |
| `lib/kskill/danawa_search.py` | k-skill 다나와 스크립트 원본 |
| `lib/danawa_ext.py` | k-skill 스크립트를 불러와 용량별 가격·판매처 수·부품 종류를 추가로 읽고, 새 검색 화면도 읽어요 |
| `lib/snapshot.json` | 가격 저장본 (`npm run snapshot`으로 새로 만듦) |
| `server/server.js` | 내 컴퓨터용 서버 (`npm start`). Vercel 함수와 같은 주소(`/api/danawa`, `/api/ask`)를 제공 |
| `server/danawa.js` | 내 컴퓨터에서 파이썬 실행, 재시도, 동시 조회 제한, 가격 캐시 |
| `server/ai.js` | 신룡 상담 (Gemini + Firecrawl). 붐비는 모델은 건너뛰고 다음 모델로 |
| `server/snapshot.js` | 가격 저장본 만들기 |
| `vercel.json` | Vercel 설정 (서울 리전, 함수 시간 제한) |
| `.env.example` | API 키 이름 예시 (복사해서 `.env`로 사용) |

## 자주 묻는 질문

**Q. 가격이 다나와 사이트와 조금 달라요.**
A. 6시간 동안 모아 둔 가격을 쓰기 때문입니다. 내 컴퓨터에서는 `data/cache.json`을 지우고 서버를 다시 켜면 새로 모읍니다. Vercel 사이트에서는 다나와가 막힌 동안 가격 저장본이 쓰일 수 있어요.

**Q. "가격 정보를 아직 충분히 모으지 못했어요"가 떠요.**
A. 다나와가 잠시 응답하지 않은 경우입니다. 1분쯤 뒤에 다시 시도하세요.

**Q. 상담 탭에서 오류가 나요.**
A. `.env`의 `GOOGLE_API_KEY`가 맞는지 확인하세요. 키를 바꿨다면 서버를 껐다 켜야 반영됩니다.

**Q. 실제로 구매도 되나요?**
A. 아니요. 가격 비교와 견적까지만 합니다. 구매는 쇼핑몰 링크를 눌러 직접 진행하세요.
